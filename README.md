# AsSuppression — мод подавления в стиле Squad (Minecraft 1.20.1, Forge)

## Что делает мод
- Затемняет края экрана настоящей плавной виньеткой (горизонтальный градиент для левого/правого
  края нарисован вручную через буфер вершин — встроенный `GuiGraphics#fillGradient` умеет
  интерполировать цвет только сверху вниз, поэтому для боковых краёв он давал не плавное
  затухание, а сплошные прямоугольники с резкой границей).
- Уводит/трясёт камеру (yaw/pitch/roll) сглаженным псевдослучайным шумом (не синусоидами) —
  движение нерегулярное, без ощущения "пружины"/качелей, при этом максимальная сила эффекта
  осталась прежней.
- Подавление растёт, когда рядом (в радиусе **2 блоков**) пролетает любая быстро летящая сущность
  (скорость ≥ 0.5 блока/тик). Даже на самом краю радиуса эффект не обнуляется полностью — еле
  заметен (минимальный множитель дистанции `MIN_EDGE_FACTOR`).
- При прямом попадании — резкий скачок подавления почти до максимума.
- **Контузия от взрыва**: экран одновременно (а) плавно темнеет (полупрозрачная тёмная заливка,
  сила зависит от `flash`) и (б) становится **по-настоящему чёрно-белым** через собственный
  пост-процесс шейдер (`shaders/post/grayscale.json` + `program/grayscale.json` +
  `core/grayscale.fsh`), а не имитацией серым фильтром поверх картинки.

### Как работает ч/б-шейдер
`BWEffectHandler` включает/выключает пост-эффект тем же публичным API, которым ванильный клиент
включает эффект тошноты (`GameRenderer#loadEffect` / `#shutdownEffect`). Пока уровень контузии
(`flash`) выше порога — весь экран проходит через `grayscale.fsh`, который переводит цвет в
градации серого по формуле яркости (0.299R + 0.587G + 0.114B). Порог, а не плавный uniform-фейд,
выбран специально: покадровое обновление uniform `Intensity` потребовало бы рефлексии в приватное
поле `GameRenderer#postEffect`, которая может отвалиться при обновлении Forge/маппингов. Плавность
самого затемнения по-прежнему есть — её даёт `SuppressionOverlay`, а шейдер добавляет к этому
настоящую потерю цвета.

Если хочешь именно плавный, без порога, переход между цветным и ч/б через uniform — это реально,
но потребует рефлексии/accessor-миксина в `GameRenderer`, могу дописать отдельным шагом.

## Структура проекта
```
assuppression-mod/
├── build.gradle
├── gradle.properties
├── settings.gradle
└── src/main/
    ├── resources/
    │   ├── META-INF/mods.toml
    │   └── pack.mcmeta
    └── java/com/asuppression/mod/
        ├── AsSuppressionMod.java              — точка входа мода
        ├── client/
        │   ├── ClientSuppressionHandler.java  — уровень подавления, детект стрел рядом, тряска камеры
        │   └── SuppressionOverlay.java        — рендер виньетки по краям экрана
        ├── network/
        │   ├── NetworkHandler.java            — регистрация канала
        │   └── SuppressionHitPacket.java       — пакет сервер -> клиент "подними подавление"

        │   └── ServerSuppressionEvents.java   — слушает попадание стрелы по игроку
        └── command/
            └── SuppressCommand.java           — команда /suppress <0..1> для тестов
```

## Сборка

В архиве нет файлов gradle wrapper (`gradlew`, `gradlew.bat`, `gradle/wrapper/...`) — их нужно
взять из официального Forge MDK, самому их генерировать не нужно.

1. Установи JDK 17.
2. Скачай официальный **Forge MDK для 1.20.1** с `https://files.minecraftforge.net/`, распакуй
   в отдельную папку — там уже готовы `gradlew`, `gradlew.bat`, `gradle/wrapper/...`.
3. Перенеси из архива этого мода в папку MDK (с заменой):
   - `src/` → поверх `src/` из MDK
   - `build.gradle`, `gradle.properties`, `settings.gradle` → поверх файлов MDK
4. В терминале, из корня папки MDK:
   - Windows: `gradlew.bat build`
   - Linux/macOS: `./gradlew build`
5. Готовый .jar появится в `build/libs/assuppression-1.0.0.jar` — его кладёшь в `mods/` обычного
   Minecraft с Forge 1.20.1.

### Быстрый тест без сборки jar
Из той же папки:
```
./gradlew runClient      (Linux/macOS)
gradlew.bat runClient    (Windows)
```
Это запустит dev-клиент Minecraft прямо с модом внутри — удобно, чтобы быстро проверить правки
в коде, не пересобирая и не копируя jar каждый раз.

## Как проверить механику в соло-мире

### Способ 1 — без стрельбы, через команду (самый быстрый)
1. Создай/открой мир с включёнными читами (Allow Cheats: ON).
2. Установи мод в `mods/` и запусти игру.
3. В чате введи:
   ```
   /suppress 1.0
   ```
   — увидишь максимальное затемнение краёв экрана и сильную тряску камеры, как при попадании.
4. Попробуй разные значения:
   ```
   /suppress 0.3
   /suppress 0.6
   ```
   чтобы увидеть промежуточные степени эффекта.
5. Для эффекта контузии от взрыва (тусклость + потеря цвета):
   ```
   /suppressflash 1.0
   /suppressflash 0.4
   ```

### Способ 2 — "по-настоящему", через лук/снежки/трезубец
1. Возьми лук и стрелы (`/give @s bow`, `/give @s arrow`) или снежки/трезубец — подойдёт
   любая быстро летящая сущность.
2. Попроси второго игрока (или используй дружественного моба со стрелами, например Skeleton)
   стрелять рядом с тобой, не попадая — экран начнёт слегка темнеть и подрагивать камера, когда
   снаряд пролетает в радиусе ~4 блоков.
3. Дай снаряду попасть в тебя напрямую — эффект будет резким и сильным, почти как маска экрана.

   Для соло без второго игрока проще всего:
   - заспавнить Skeleton рядом (`/summon minecraft:skeleton`) и дать ему стрелять по тебе;
   - либо просто стрелять из лука самому в стену рядом с собой и подходить к траектории —
     это не даст прямого попадания, но продемонстрирует "близкий пролёт".

### Способ 3 — проверка контузии через настоящий взрыв
1. `/give @s tnt` → поставь блок TNT рядом с собой (не под ногами!), подожги и отойди на
   безопасное расстояние 5-10 блоков (сама механика TNT это не отменяет — не взорвись).
2. В момент взрыва экран должен потускнеть и "выцвести" — это и есть эффект контузии.
3. Либо просто используй `/suppressflash 1.0` для теста без риска для персонажа.

## Как подключить эффект к своему оружейному моду (если он появится)
Из любого места клиентского кода (например, при спавне кастомного снаряда-"пули" рядом с игроком):
```java
com.asuppression.mod.client.ClientSuppressionHandler.addSuppression(0.15f); // близкий пролёт
```
А при попадании по игроку — с сервера отправь `SuppressionHitPacket`, как это делает
`ServerSuppressionEvents`, только вместо проверки `AbstractArrow` подставь свой класс снаряда.

## Если шейдер не грузится (troubleshooting)
Формат `.json`/`.vsh`/`.fsh` для пост-эффектов у Mojang нигде официально не задокументирован —
он собран по образцу ванильных эффектов (`nausea.json` и т.п.) и должен рабочим "из коробки", но
если при заходе в мир в логе будет ошибка вида `Failed to load shader` или `Could not resolve shader`,
первым делом проверь:
- Файлы лежат ровно так: `assets/assuppression/shaders/post/grayscale.json`,
  `assets/assuppression/shaders/program/{grayscale,blit}.json`,
  `assets/assuppression/shaders/core/{grayscale.vsh, grayscale.fsh, blit.fsh}`.
- В логе (`logs/latest.log`) ищи `assuppression` и `shader` — там будет точная причина
  (несовпадение имени uniform/sampler, синтаксическая ошибка в GLSL и т.п.).
- Если проблема в конкретной строке GLSL — кинь мне лог, поправим.

## Настройка силы эффекта
В `ClientSuppressionHandler`:
- `DECAY_PER_TICK` — скорость затухания подавления.
- `NEAR_MISS_RADIUS` — радиус реакции на пролетающую "пулю" (сейчас 2 блока).
- `NEAR_MISS_STRENGTH` — сила подавления от близкого пролёта.
- `MIN_EDGE_FACTOR` — минимальный (еле заметный) эффект на самом краю радиуса.
- `FAST_ENTITY_SPEED_THRESHOLD` — с какой скорости (блоков/тик) сущность считается "пулей".
- `FLASH_DECAY_PER_TICK` — скорость затухания контузии (по умолчанию медленнее, чем подавление).
- Числа в `smoothNoise(...)` вызовах внутри `onComputeCameraAngles` — амплитуда (5.0, 3.2, 1.6 и т.д.)
  и период смены случайного значения в мс (90, 47, 110...) — крути период, если хочешь более
  резкий/более плавный джиттер.

В `BWEffectHandler`:
- `ACTIVATE_THRESHOLD` — при каком уровне контузии включается ч/б-шейдер.

В `ServerSuppressionEvents`:
- `DIRECT_HIT_INTENSITY` — сила подавления при прямом попадании.
- `FAST_HIT_SPEED_THRESHOLD` — минимальная скорость снаряда, чтобы попадание засчиталось как "пулевое".
- `EXPLOSION_RADIUS` — радиус, в котором чувствуется взрыв.
- множители `falloff * 1.2f` / `falloff * 0.9f` в `onExplosionDetonate` — сила flash/тряски у эпицентра.
